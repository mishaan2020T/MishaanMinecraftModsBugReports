# MishaanMinecraftModsBugReports
This repository is for submitting issues/bugs related to my Minecraft mods.
# What types of issues are allowed?
1. An issues related to any of my mod
2. The bug problems related to ane of my mods
3. Do you want a certain feature to be added to a mod? Post it here!
# Issue creation rules
  **Templates:**
  
  ===A bug===
  
  1. Mod name, mod version, platform(Forge,Neoforge,Fabric,...)
  2. Bug description
  3. Issue type (Specifically, enter "Bug" here)

  ===Wanted features===

  1. Mod name
  2. What do you want to add(Long description)
  3. Issue type (Specifically, enter "Feature" here

  ===Other issues===

  1. Mod name, mod version, platform(Forge,Neoforge,Fabric,...)
  2. Description of your issue
  3. Issue type (Specifically, enter "Other" here)

**Rules:**

1. Issues must follow the established template.
2. It is prohibited to submit issues containing inappropriate content (NSFW, profanity, etc.), issues unrelated to the repository, or issues with incorrect information (mod name, version, platform).
3. Issues deemed incorrect may not be reviewed.
4. We may not be able to process all submitted issues in a timely manner; consequently, there may be delays in implementing fixes or adding new features.
5. Spamming the repository with multiple identical issues from the same user (i.e., submitting many duplicate issues at once) is prohibited.
